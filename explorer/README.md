# alto-explorer

Visualize `alto` activity.

## Status

`alto-explorer` is **ALPHA** software and is not yet recommended for production use. Developers should expect breaking changes and occasional instability.

## Configuration

The explorer verifies every notarization and finalization in the browser: each certificate carries one FN-DSA-512 (Falcon) signature per quorum signer, which the explorer checks (with `alto-types` compiled to WebAssembly) against the network's identity, the encoded set of validator public keys.

When an indexer serves the explorer, its `/runtime-config.js` supplies the identity, validator keys, validator locations, and description of its network, and requests use the same origin as the explorer page. A map of validator locations appears when the configuration lists locations.

A standalone explorer (for example, `npm start`) loads the bundled `public/runtime-config.js`, which selects `src/local_config.ts`. If the configuration script fails to load, startup stops with a refresh prompt. To browse a local network from source, set `PUBLIC_KEY_HEX` in `src/local_config.ts` to the network's hex-encoded participant set (the indexer's `--identity`):

```typescript
// Indexer host and port (the scheme matches the explorer page)
export const BACKEND_URL = "localhost:8080";

// Hex-encoded participant set
export const PUBLIC_KEY_HEX = "...";

// Empty locations hide the map
export const LOCATIONS: [[number, number], string][] = [];
```

For a network generated by `deploy`, the `explorer` subcommand writes this file:

```bash
cargo run --bin deploy -- explorer --dir <config-dir> --backend-url localhost:8080
cp <config-dir>/config.ts src/local_config.ts
```

Then run:

```bash
npm start
```

## Development

### Build the app

```bash
npm run build
```

_This compiles the WASM module from `alto-types` and checks it against `scripts/fn_dsa_fixture.json` before building the React app. On macOS, set `CC` and `AR` to Homebrew LLVM's `clang` and `llvm-ar`._

### Run the production build

_Install `serve` if necessary: `npm install -g serve`._

```bash
serve -s build
```
